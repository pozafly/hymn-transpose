# 새찬송가 디지털 악보 원본 조사

조사일: 2026-09-24

## 결론

새찬송가 645장을 전부 직접 사보할 필요는 없어 보인다. 공개 첨부된 MuseScore 원본 645개를 실제로 내려받아 파일 수와 압축 무결성을 확인했다. NWC 전곡 모음에도 645개 파일이 들어 있다.

다만 파일 존재와 악보 정확도, 변환 품질, 서비스 재배포 권한은 각각 별개다. 이번 조사는 원본의 존재와 구조를 확인한 단계이며, 변환·조옮김 검수나 서비스 등록은 하지 않았다.

## 1순위: 깔끔이 CCM의 MuseScore 원본

[원본 게시물 목록](https://ccm4u.tistory.com/category/Musescore/새찬송가%20뮤즈스코어%20악보)

작성자가 직접 악보 작업에 사용한 `.mscz` 파일이라고 설명한다. 2022-04-07에 7개 게시물로 나누어 공개했다. 압축 비밀번호도 게시물 본문에 공개되어 있다.

실제 첨부파일 다운로드 및 검사 결과:

| 범위 | MSCZ 파일 수 | ZIP 무결성 검사 |
| --- | ---: | --- |
| 1–100 | 100 | 통과 |
| 101–200 | 100 | 통과 |
| 201–300 | 100 | 통과 |
| 301–400 | 100 | 통과 |
| 401–500 | 100 | 통과 |
| 501–600 | 100 | 통과 |
| 601–645 | 45 | 통과 |
| 합계 | 645 | 장 번호 1–645 누락 없음 |

압축 내부의 MSCX XML을 표본 검사했다. 다음 수치는 XML 요소 개수이며 음악적 정확성을 보증하지 않는다.

| 표본 | MuseScore 파일 버전 | 보표 ID 수 | Note 요소 | Lyrics 요소 | Harmony 요소 |
| --- | --- | ---: | ---: | ---: | ---: |
| 67장 | 3.02 | 2 | 184 | 170 | 0 |
| 104장 | 3.02 | 2 | 236 | 149 | 0 |
| 645장 | 3.02 | 2 | 99 | 56 | 0 |

세 표본 모두 한글 문자열과 음표·가사 요소가 있다. 이미지가 아니라 편집 가능한 악보 데이터다. 가사 전체의 정확성, 성부·붙임줄·임시표·절 수는 아직 대조하지 않았다.

표본에서 구조화된 코드 심볼인 `Harmony` 요소는 발견되지 않았다. 코드명이 다른 텍스트 형태로 들어 있는지와 전곡의 코드 유무는 별도 확인이 필요하다. 현재 앱의 I/IV/V/V7 코드를 모든 곡에 임의로 적용하면 안 된다.

작성자도 잘못 그려진 부분이 있을 수 있으며 직접 수정해서 사용하라고 안내한다. 게시물 하단에 저작자표시 CCL 링크가 있지만, 이것만으로 포함된 모든 곡·가사·편곡의 서비스 이용 권한을 확인했다고 볼 수는 없다.

## 대안: NWC 전곡 모음

[새찬송가 전곡 NWC 파일모음](https://nmcat.tistory.com/93)

- 2018-02-11 게시. 소프라노·알토·테너·베이스 파트별 재생을 안내한다.
- 첨부 ZIP을 실제 다운로드해 `.nwc` 파일 645개가 들어 있음을 확인했다.
- 개별 악보의 가사 인코딩과 악보 정확도, 변환 결과는 검증하지 않았다.
- [nwsw/nwc2musicxml](https://github.com/nwsw/nwc2musicxml)은 NWCtxt 입력을 대상으로 하며, README에 코드 심볼·레이아웃 등의 미지원 항목을 안내한다.
- [zz85/nwc-viewer](https://github.com/zz85/nwc-viewer)는 바이너리 NWC 파서와 MusicXML 변환 CLI를 제공한다. 우리 악보에 대한 호환성은 별도 시험이 필요하다.

MuseScore 원본을 확보했으므로 NWC 경로는 누락·오류 곡을 비교하는 보조 자료로 두는 편이 적절하다.

## 공식 자료와 이용 조건

[한국찬송가공회 공식 앱 소개](https://play.google.com/store/apps/details?id=com.hymnkorea.archive)는 공회가 관리하는 표준 데이터에 기반한 새찬송가 645장의 가사·악보 제공을 명시한다. 편집 가능한 원본 파일이나 외부 API 제공 여부는 확인하지 못했다.

[공회 저작권 안내](https://hymnkorea.org/21)의 **6. 앱** 항목은 새찬송가·통일찬송가 곡을 사용한 앱 제작을 명시하며, 저작권료는 공회에 문의하도록 안내한다. 웹 검색 도구에서는 해당 페이지가 403으로 표시됐지만, 직접 HTTP 요청으로 본문을 확인했다.

공개 서비스 도입 전에 확인할 내용:

- 표준 악보의 MusicXML·MuseScore 등 편집 가능한 원본 제공 가능 여부
- 웹에서 조옮김한 악보를 보여주고 PDF/PNG로 배포하는 이용 범위
- 한국어 가사와 편곡을 포함하는 관리 범위 및 곡별 예외
- 무료 서비스·광고·유료 기능에 따른 계약 조건
- 원본 사보 파일 제공자의 이용 조건과 출처 표기

별도 문의나 메시지는 보내지 않았다. 앱별 요금이나 원본 데이터 공급 여부도 확정하지 않았다.

## 기술 도입 제안

추천 시험 경로는 `MSCZ → MusicXML → LilyPond 소스 → 기존 렌더러`다.

- MuseScore는 [공식 내보내기 문서](https://handbook.musescore.org/en_gb/file-management/file-export)에서 MusicXML 출력을 지원한다.
- LilyPond의 [musicxml2ly 문서](https://lilypond.org/doc/v2.24/Documentation/usage/invoking-musicxml2ly)는 음표·악상·악보 구조·가사를 `.ly`로 가져오는 기능을 설명한다.
- 변환 후 보표 구성·가사 배치·줄바꿈이 기존 인쇄본과 일치하는지는 검수해야 한다. 자동 변환만으로 원본 레이아웃 재현을 보장하지 않는다.
- `musicxml2ly`는 Python 기반 도구다. 이를 채택한다면 등록 전 변환 도구에서만 사용하고 웹앱과 렌더러는 Node.js로 유지할 수 있다. Python을 도구까지 완전히 제외하려면 다른 변환 경로를 별도로 평가해야 한다.
- 곡별 기준조·장단조·박자를 보존해야 한다. 기존 67장 템플릿의 `\key ges`와 레이아웃을 변경하는 방식으로 일반화하면 안 된다.

다음 단계는 **67장, 단조인 104장, 짧은 아멘송 645장**의 시험 변환이다. 입력시간 절감 효과, 가사·음표 보존, 코드 심볼 보완량과 레이아웃 수정량을 확인한 뒤 전곡 처리 규모를 판단한다.
