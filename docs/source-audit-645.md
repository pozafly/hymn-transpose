# 645장 원본 검사·수정 기록

검사일: 2026-09-24. 사용자 요청에 따라 **서버로 옮길 MuseScore 원본**을 검사했다.
기존 1~80장 검사 결과를 재사용하고, 81~645장 565곡을 추가 검사했다.
기존에 발견한 22·42·63장 가사 차이는 참고 자료를 추가 대조했다.

## 결과

- 원본 645개: 번호 1~645 누락·중복 없음. 원래 파일은 별도 보관했다.
- 추가 565곡: ZIP 내부 XML, 음높이와 음 이름의 일치, 붙임줄의 실제 연결 대상, 성부 내 시간 중첩을 검사했다.
- 수정본을 포함한 565곡을 MuseScore 3.6.2로 읽어 검수용 MusicXML과 비교했다. **음표 140,034개, 가사 부착 항목 116,107개**, 조표·박자가 곡별로 모두 일치했다.
- 음표 비교에는 보표·성부·마디·시작 위치·음길이·MIDI 음높이·이명동음 철자·붙임줄 시작/끝을 포함했다. 단순 개수 비교가 아니다.
- 가사는 [한국찬송가공회](https://hymnkorea.org/50)와 [GOODTV](https://goodtvbible.goodtv.co.kr/hymn)의 전곡 자료로 대조했다. 후렴, 합창 성부, 반복 구간, 절을 두 줄에 나눠 적은 경우를 구분하고 차이 나는 표현은 악보 이미지도 확인했다.
- **6곡 원본 수정: 112·133·220·244·451·519장.** 나머지 639개 원본 파일은 바이트 단위로 동일하다.

원조 조표, 박자, 가사, 음길이를 유지했으며 음높이 이동을 직접 계산하지 않았다.

가사 수정 근거: [220장 악보](https://tripol.tistory.com/2057), [519장 악보](https://tripol.tistory.com/2367) 및 위 두 가사 자료.

133·244장은 음표를 삭제해 개수를 맞추지 않았다. 성부만 분리하여 겹친 이벤트를 보존했다.
이때 두 번째 성부의 기본 음표 기둥 방향을 새 성부에도 명시해 배치 변화를 막았다.
133장의 1페이지 구성도 유지됨을 확인했다. 기존 Style·페이지·줄바꿈 설정은 변경하지 않았다.
수정한 파일의 오래된 미리보기 썸네일만 제거했다.

## 수정 후 확인

수정한 6곡은 **MuseScore 3.2.3과 3.6.2 양쪽**에서 원본 데이터와 검수용 MusicXML의 음표 이벤트가 일치했다.
기존 가져오기 코드의 파싱·음표 수 확인·LilyPond 문법 생성도 6곡 모두 통과했다.
이전 등록 실패 4곡(112·133·244·451)의 실패 조건을 원본 수정으로 해소했다.

원본은 MuseScore 3.6.2로 저장되어 있다. 기존 3.2.3 도구는 최신 형식 경고를 출력했지만,
133·244장의 누락은 3.6.2에서도 재현됐다. **버전 차이만이 원인은 아니며 성부 시간 중첩이 직접 원인이었다.**

수정한 6곡만 검수용 이미지로 열어 한글 가사와 악보 배치를 확인했다.
전곡 PDF/PNG 생성, 앱 코드 추가 수정, 운영 DB·캐시 수정, 서버 배포는 이번 작업에 포함하지 않았다.
유닛·E2E 테스트는 실행하지 않았다.

## 원본을 유지한 가사 차이

22·42·63장의 기존 표현은 GOODTV와 인쇄 악보 이미지에서 확인했다.
따라서 원본을 바꾸지 않았다: [22장](https://tripol.tistory.com/1823), [42장](https://tripol.tistory.com/1847), [63장](https://tripol.tistory.com/1872).

웹 자료 두 곳이 일치해도 원본 오류로 단정할 수 없었다.
예를 들어 392장의 ‘눈물을’, 526장의 조사, 338장의 ‘베개’, 613장의 조사는
원본 표기가 인쇄 악보와 일치하여 유지했다.
근거: [392장](https://tripol.tistory.com/2236), [526장](https://tripol.tistory.com/2374), [338장](https://tripol.tistory.com/2178), [613장](https://tripol.tistory.com/2461).

## 검사의 범위와 남는 한계

**전곡 파일 검사와 확인된 오류 수정은 완료했지만, 출판사 정본의 모든 음표를 사람이 대조한 인증은 아니다.**

보조 자료로 [별도 배포된 NWC 645곡](https://nmcat.tistory.com/93) 중 신규 565곡과 기존 가사 차이 3곡을 읽었다.
별도 배포처라는 이유만으로 독립적인 입력 원본이라고 보장할 수는 없다.
NWC를 읽는 공개 도구와 편곡·조·아멘·반복·성부 배치 차이에도 영향을 받으므로, 이 비교만으로 음표를 바꾸지 않았다.

수정 전 원본 568곡 중 484곡에서 모든 성부의 음표 집합이 보조 자료와 일치했다.
이 비교는 곡 전체의 일정한 조 차이를 허용하고 같은 시점의 유니즌을 합친 값이며,
일부 비정규 마디의 빈 여백을 비교용으로 줄였다. 따라서 위의 565곡 원본→MusicXML 정밀 검사와는 다른 검사다.
나머지 84곡의 차이도 위치와 음높이를 기록했다. 이 숫자는 오류 곡 수가 아니며 위의 수정 곡도 포함한다.
차이 중에는 참고 NWC의 임시표 차이, 아멘 유무, 분할 기보, 반복·합창 편성 차이가 포함된다.
인쇄본으로 대조한 여러 후보는 오히려 현재 MuseScore 원본이 맞았다.
보조 자료와의 미해결 차이를 임의로 정답 처리하지 않았으며 상세 비교 자료를 남겼다.

## 파일과 서버 이전

모든 악보·가사·검수 중간 산출물은 Git 제외 경로 `data/source-review/`에 있다.

- `original/`: 다운로드 원본 645개, 수정하지 않음.
- `corrected/`: 수정된 6개 원본만 저장.
- `reports/changes.json`: 수정 전후 SHA-256과 정확한 수정 위치·유형.
- `reports/bulk-event-verification.json`: 81~645장 곡별 정밀 대조 결과.
- `reports/invariants.json`, `overlaps.json`, `refined-lyrics.json`, `all-note-comparison.json`: 상세 검사 자료.
- `release/hymn-originals-reviewed-20260924.zip`: 서버 전송용 묶음. 내부에 번호 구간별 원본 ZIP 7개, 안내문, 파일별 해시와 검사 요약만 포함.

서버 전송용 묶음에는 PDF·PNG·검수용 MusicXML·DB·다운로드한 참고 자료를 넣지 않는다.
원본 악보와 압축파일은 GitHub에 올리지 않는다.

현재 `scripts/import-hymns.ts`는 이미 등록된 ID를 건너뛴다.
따라서 서버에서 ZIP만 교체하거나 기존 가져오기 명령을 다시 실행하는 것만으로는
이미 등록된 악보가 수정본으로 바뀌지 않는다. 서버의 기존 등록 상태에 맞는 재등록이 별도로 필요하다.
